# GPT-6 Astra

A clean, professional ChatGPT-style interface powered by **OpenAI GPT-6 Astra** via [Puter.js](https://developer.puter.com).

## Features

- **ChatGPT-like UI** — Dark theme, smooth animations, and modern design
- **GPT-6 Astra** — OpenAI’s most capable model for complex reasoning, coding, research, and professional work
- **No API keys required** — Powered by Puter.js (user-pays model)
- **Conversation history** — Saved locally in your browser
- **New chat / Delete chats** — Full sidebar management
- **Typing indicator** — Visual feedback while the model is thinking
- **Markdown support** — Code blocks, bold, lists, and headers
- **Responsive** — Works on desktop and mobile
- **Suggestion cards** — Quick-start prompts on the welcome screen

---

## How to Use

1. Open the [live demo](https://youssefth98.github.io/-GPT-6-Astra/) or open `index.html` locally in your browser
2. Type a message and press **Enter** (or click the send button)
3. Your conversations are automatically saved in the browser

> **Note:** The first time you use it, Puter.js may ask you to sign in. This is required so you can access the AI models.
